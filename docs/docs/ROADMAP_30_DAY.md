# FitPair 30-Day Build Roadmap

## Week 1: Foundation
- Finalize MVP features
- Set up GitHub structure
- Set up Bubble.io app
- Create Supabase project
- Define database tables
- Build brand direction

## Week 2: Core App Screens
- Landing page
- Sign up / login
- Onboarding flow
- Profile setup
- Discover page
- Match/activity cards

## Week 3: Functionality
- User profiles
- Interest matching
- Messaging basics
- Events page
- Report/block safety tools

## Week 4: Beta Launch Prep
- Test app flows
- Fix bugs
- Create private beta invite list
- Build feedback form
- Prepare launch content
- Invite first test users

## 30-Day Goal
Have a simple, working FitPair MVP ready for private beta testing.
