# FitPair User Onboarding Flow

## Step 1 — Welcome Screen
Headline:
"Real-world connection starts here."

CTA Buttons:
- Create Account
- Log In

---

## Step 2 — Account Creation
User enters:
- Email
- Username
- Password
- Age range
- City/location

---

## Step 3 — Choose Interests
Users select activities/interests:
- Gym
- Running
- Hiking
- Yoga
- Basketball
- Coffee walks
- Wellness events
- Dance
- Cycling
- Boxing

Goal:
Personalize recommendations and matching.

---

## Step 4 — Profile Setup
User adds:
- Profile photo
- Short bio
- Fitness goals
- Social goals
- Activity level

---

## Step 5 — Discover Feed
User sees:
- Nearby people
- Activity groups
- Upcoming events
- Suggested matches

---

## Step 6 — Match & Connect
Users can:
- Send interest requests
- Match with users
- Join events
- Start messaging

---

## Step 7 — Safety & Trust
Display:
- Community guidelines
- Safety reminders
- Reporting/block tools
- Respect-first culture

---

## Onboarding Goal
Help users feel safe, welcomed, motivated, and excited to build real-world connections.
