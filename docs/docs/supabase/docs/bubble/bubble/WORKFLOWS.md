# FitPair Bubble.io Workflows

## Account Workflows
- Create account
- Log in user
- Log out user
- Save onboarding answers

## Profile Workflows
- Upload profile photo
- Edit bio
- Update city
- Add/remove interests
- Save activity goals

## Discover Workflows
- Load nearby users
- Filter users by interest
- View profile
- Send connection request

## Match Workflows
- Create match when both users show interest
- Unlock messaging after match
- Show shared interests

## Messaging Workflows
- Send message
- Load conversation
- Display unread message indicator

## Event Workflows
- Create event
- Join event
- Leave event
- View event details

## Safety Workflows
- Report user
- Block user
- Hide blocked users from Discover
- Prevent blocked users from messaging

## MVP Workflow Goal
Make FitPair functional enough for private beta without overbuilding.
