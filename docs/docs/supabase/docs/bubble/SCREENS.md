# FitPair Bubble.io Screen Plan

## 1. Landing Page
Purpose:
Introduce FitPair and drive signups.

Sections:
- Hero headline
- Mission statement
- Benefits
- Create account button
- Login button

---

## 2. Sign Up / Login
Fields:
- Email
- Password
- Username

Actions:
- Create account
- Log in existing user

---

## 3. Onboarding
Screens:
- Choose city
- Select interests
- Add profile photo
- Add short bio
- Select activity goals

---

## 4. Home / Discover
Displays:
- Suggested people
- Shared interests
- Nearby activities
- Events

---

## 5. Profile Page
Displays:
- Profile photo
- Bio
- City
- Interests
- Activity goals

---

## 6. Match Page
Displays:
- Mutual interests
- Suggested connection
- Connect button
- Message button after match

---

## 7. Messages
Displays:
- Conversation list
- Message thread
- Send message box

---

## 8. Events
Displays:
- Upcoming events
- Event details
- Join event button

---

## 9. Safety Center
Displays:
- Report user
- Block user
- Community rules
- Safety reminders

---

## MVP Screen Goal
Keep the first version simple, clean, safe, and focused on real-world connection.
