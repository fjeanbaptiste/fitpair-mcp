# FitPair MVP Features

## Core Purpose
FitPair helps people connect in real life through fitness, hobbies, activities, wellness, and community.

## MVP Features

### 1. User Accounts
- Sign up
- Log in
- Basic profile setup
- Profile photo
- Location/city
- Age range
- Fitness/activity interests

### 2. Interest-Based Matching
- Match by shared activities
- Match by fitness goals
- Match by hobbies
- Match by location

### 3. Activity Profiles
Users can choose interests like:
- Gym
- Walking
- Running
- Basketball
- Hiking
- Yoga
- Boxing
- Dance
- Coffee walks
- Wellness events

### 4. Discover Page
- View nearby people
- View activities
- View communities
- Filter by interest

### 5. Messaging
- Simple direct messages
- Only after mutual interest/match
- Safety-first communication

### 6. Events
- Community events
- Fitness meetups
- Hobby-based meetups
- Beginner-friendly activities

### 7. Safety
- Report user
- Block user
- Profile verification later
- Community guidelines

## MVP Goal
Launch a simple, premium, safe version that proves people want real-world connection through shared activities.
